# Їжа та стіки

PWA-трекер прийомів їжі та стіків IQOS. Рахує, коли можна курити після їжі (пауза 2 год), веде план прийомів від сніданку і статистику стіків по днях.

- Дані зберігаються локально (IndexedDB), є експорт/імпорт JSON для бекапу.
- Працює офлайн (service worker).
- На iPhone: відкрити в Safari → Поділитися → «На екран Домівка».

Іконки інтерфейсу: [Lucide](https://lucide.dev) (ISC).
